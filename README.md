## 插件概览

### 对话增强
作为系统的核心展示层，负责高性能的消息渲染管线。
- [ ] 目前还在尝试兼容前端卡中，前端卡暂不可用中

- **内容协议渲染**：基于 LuminaView 渲染引擎，自动识别并剥离深层协议标签（如思考链、内部指令），仅将最纯净的剧情呈现给用户。
- **流式平滑显示**：深度优化的 Token 步进算法，彻底解决大模型输出时的“跳变”感，提供书籍阅读般的柔顺体验。
- **跨模式组件化**：支持在对话流中直接嵌入交互式 UI（如选择肢、小游戏、状态卡片），通过双向通讯协议实现真正的沉浸式交互。

### 导演引擎 *- 兼职记忆表格*
负责剧情推演与状态调度的核心中控系统。

- **实时协议驱动**：利用 XML 标签捕获技术，动态解析模型输出的规划指令，实现生成过程中的精准逻辑校准与语境干预。
- **自动剧情摘要**：在生成间隙自动提炼关键事件与人物变动。支持将摘要实时同步至记忆总线，确保持续生成的连贯性。
- **多层级记忆调度**：打通从短期上下文到长效世界书的调度链路。通过向量检索与关键帧技术，动态喂给 AI 最相关的情报。

### 制卡工坊 *- Agent 交互，你只需要告诉模型你的想法即可，它会帮你完成剩下的工作*
Agent 自动构建人设与世界观创作流程。采用“规划者-执行者”分离架构，支持虚拟工作区暂存、基于组件化协议的结构化信息采集，现在你可以通过简单的选项确认即可高效完成复杂的制卡任务。

- **记忆管理系统**：具备独立的文件化记忆树，自动保存你的偏好约束、参考片段与设定决议，确保模型在后续创作中始终锚定核心。
- **规划执行分离架构**：利用专用规划模型进行逻辑构思，配合隔离的执行模型进行细节重写，彻底告别长上下文导致的逻辑偏移。
- **组件驱动交互**：内置丰富的结构化收集组件，通过可视化表单与选项组代替枯燥的问答，大幅提升信息采集效率。
- **虚拟工作区审阅**：所有生成结果默认进入虚拟暂存区，确认无误后方可物理落盘至世界书，给予你绝对的控制权。


### 幻光时间线 *- 剧情时间线*
将线性对话重塑为无限可能的树状世界线。

- **树状分支管理**：像管理 Git 版本分支一样管理剧情。点击任意节点即可创建平行世界线，轻松尝试不同的发展路径（A/B 测试）。

## 核心设计原则

- **绝对隔离**：插件间的代码逻辑保持独立，仅通过 API 核心或全局状态管理进行受控的数据通信。
- **声明式注册**：插件通过清单接口声明其 UI 组件、菜单入口、设置项以及对 XML 标签的处理权限。
- **响应式驱动**：视图层深度绑定响应式状态机，确保底层逻辑变更能即时反馈至用户界面。
- **宿主中立**：通过适配器层屏蔽不同部署环境（如网页版或原生版）的物理差异，确保插件逻辑的一致性。

## 运行环境与架构适配

本插件具备高度的环境自适应能力，支持以下运行形态：

### 1. 基础模式
- **纯前端插件运行**：支持作为标准的 SillyTavern 插件直接安装。在无后端插件环境下，系统自动切换至轻量化运行模式，利用浏览器存储或宿主原生接口完成基础同步。
- **TauriTavern 适配**：针对 TauriTavern 进行了适配 Api 代替后端进行数据持久化。通过内置的桥接协议自动对接嵌入式 ABI，允许插件在移动端环境下得到稳定的存储性能与更稳定的流式通讯。

### 2. 增强模式
通过部署配套的 Lumina Server 后端插件，插件将激活完整的“深度增强”特性：
- **事务化持久化**：启用基于序列对账与幂等校验的写操作协议，确保在复杂世界线切换与并发生成时的数据绝对安全。
- **统一会话引擎**：主聊天、制卡工坊等多种会话模型收敛为统一的文档结构，支持跨会话的记忆关联。
- **高性能生成控制**：利用服务器端集成的官方 SDK 路由，提供更稳健的流式连接管理与状态对账。这就是说你可以关闭网页也能继续生成消息，生成一半刷新网页插件也能自动恢复生成中状态。
- **异步剧情导演**：开启导演引擎的后台异步模式，支持在生成间隙自动执行剧情摘要提取与长线记忆回灌。（鸽了，现在只支持占用主Api的轻量模式）

## 界面外观与交互模式

插件提供两种截然不同的交互形态，用户可根据设备与个人偏好随时切换：

- **传统桌面模式**：采用经典的侧边栏与主面板嵌套布局。所有的插件功能均在固定的辅助窗口中运行，适配传统桌面用户的单任务/多标签操作习惯。
- **自由工作台模式**：引入先进的“台前调度”模型。支持多窗口自由拖拽、无级缩放、层级覆盖与前台聚焦。该模式非常适合在平板或大屏幕环境下进行多任务并行操作 ~~手机就不要尝试开这个模式了~~，**让你在等待模型回复的同时，能同时在制卡插件聊你的想法、编辑世界书条目等。**
- **客制化计划**：当前版本 UI 皮肤处于内建锁死状态。我们计划在后续迭代中开放深度的主题客制化接口，允许用户自由定义配色方案、字体权重以及组件的视觉样式，甚至是整个插件的交互形态。

## 开发与扩展规范

- **插件注册**：新增功能模块需在指定的注册文件中完成声明。
- **通讯契约**：子插件应优先消费系统提供的标准服务，避免直接穿透至宿主原生环境。
- **样式准则**：强制使用范围化样式隔离以保障沙盒效果，严禁全局样式污染。
- **国际化**：所有界面文本需通过语言包模块进行管理，严禁在代码中硬编码显示文案。
