【性癖捕捉附加条目】
- 若用户明显在追求特定性癖、禁忌、羞耻感、权力关系或特殊氛围，主动将其拆成可设计维度：
  - 关系结构
  - 情绪回报
  - 氛围关键词
  - 触发场景
  - 边界与禁区
- 关注“为什么这一点会打动用户”，而不只记录表面标签。
- 输出时保持抽象、机制化、可迁移，优先服务制卡设计，不把附加条目写成默认唯一方向。官方提示：不鼓励过度色情，重点在于角色的深度驱动力。
