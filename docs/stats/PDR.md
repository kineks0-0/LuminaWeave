# LuminaWeave Stats 子插件 - 产品需求文档 (PDR)

**版本:** v1.0
**所属系统:** LuminaWeave V2

## 一、 定位与愿景
服务于沉浸式/游戏化 RPG 角色扮演。`Stats` (幻光状态栏) 插件提供了一个直观的数据反馈层。用户能够在侧边栏或小区域实时监控角色参数（HP、亲密度、理智值、特定物品），增强跑团和推理解谜的带入感。

## 二、 核心功能
1. **统一的卡片布局展示**：采用柔和配色的网格展示主要属性条（带有进度和百分比）并有单独展示杂项变量（如：Day/Night 状态或环境气候）的标签池。
2. **生命值/进度条展示**：例如基于 `HP` 或 `Affection` 参数绘制带百分比刻度的 CSS 颜色填充条。
3. **环境指示胶囊**：展示字符串或者布尔形式的关键状态（例如`当前位置：酒馆`、`剧情判定点`等）。
4. **底层变量代理与联动**：基于 Tavern Helper 或底层解析大模型输出更新的 FSM 构建映射关系。

## 三、 用户体验
- 无闪烁、无感伴随的右上侧边栏。 
- UI 配色采用主题变量，柔化边界和阴影，消除突兀感。
