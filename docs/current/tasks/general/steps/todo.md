# LuminaWeave (幻光织机) - 待办事项列表 (TODO)

基于项目最新的《LuminaWeave 架构与功能规划 v3.6》和当前的开发进度，以下是项目尚未完成、需要后续演进的功能模块与打磨工作：

## 一、 核心交互补齐与 API 对接验证
目前界面的骨架和数据管理引擎（本地代理）已搭建完毕，但最终与底层 AI 的真实输入输出通道需要补齐：
- [x] **全景模式全链路收发测试**：确保在大窗口底部发送文字能够如原版一样完美触发 AI 回复，接收结束后自动滚动。
- [x] **“重新生成(Regenerate)”与分支逻辑联调**：将气泡上的重生成操作正确挂载到底层 API 引擎 (`triggerGenerate`) 上，支持 `swipe` 和覆盖重写能力。将聊天气泡中的 Branch 按钮桥接到 **Git 风格多轴穿梭**，并实现智能剪枝以保持界面整洁。
- [x] **Tavern Helper 深度接入**：编写 `tavernHelper.js` 装饰类代理，实现全局存取游戏化数值，用于填充大窗口状态栏。
- [ ] **ST-Prompt-Template 接入**：编写 `promptTemplate.js` 桥接服务，暴露世界线跳转和历史注入 API 供 ST 内置的 EJS 模板引擎调用。
- [ ] **环境降级与兼容侦测**：实现宿主感知函数，若用户未开启先决条件的第三方依赖，应用应能静默降级而不导致黑屏或白屏。

## 二、 阶段 3：状态机制接入 (Lumina Status)
围绕有限状态机 (FSM) 进行实时游戏化数据展示引擎的开发：
- [ ] **统一增量更新引擎 (Incremental Engine)**：在 `api/index.js` 或 Core 层拦截 AI 产生的原子指令 (如 `Modify("status.health", -10)`)。
- [ ] **全局状态树 (JSON Tree) 绑定**：维护独立于聊天记录的结构化字典以存放游戏数据。
- [ ] **Lumina Stats UI 联动**：将右侧或顶部的状态面板挂载至事件总线。数值变更时，需附带红蓝高亮、闪烁或图标翻转等 UI 动效反馈。

## 三、 阶段 4：记忆图谱与逻辑赋能 (Lumina Memory)
大长篇跑团记忆管理的杀手锏功能：
- [ ] **无缝规则绑定**：引入节点动态挥发规则，用户设定的 `/rule` 指令仅对当前世界线及其未来生效，回溯时间线时过去的节点不被污染。
- [ ] **语义切章与主动检索**：实现基于 Token 限制或轮次的“自动分章”存储能力，支持大模型通过后门 API 检索此前的特定章节内容以防止幻觉。
- [ ] **关系图谱提取**：将繁复的对话转换为精炼实体网连接（Entity-Relationship），大幅度砍断 Context 上下文体积占用。

## 四、 阶段 5：幻光枢纽编排器 (Lumina Nexus)
将模型分发策略交给硬核玩家：
- [ ] **图形化请求路由 (Visual Orchestrator)**：开发一套支持拖拽连线的数据流配置面板。
- [ ] **请求组策略 (Piggyback vs Batching)**：配置哪些模块的数据并入主线发送请求、哪些交由本地低开销模型（如 Gemini Flash）在后端并发捞取处理。

## 五、 阶段 6：幻光工坊完善 (Lumina Forge)
- [ ] **偏好矩阵配置管理**：独立的全屏设定界面，管理包括 越狱 Prompt、渲染样式、生成参数等一套预设偏好。
- [ ] **一键制卡与环境加载**：选择对应偏好模板一键应用到新开或当前的聊天时间线内。

## 六、 阶段 7：高级存储分发与统一设置 (Storage & Unified Settings)
重构全局存储能力，并为用户提供集中化的视图配置中心：
- [ ] **Data Scoping Engine (存储作用域代理)**：在 `api/storage.js` 提供独立的抽象层，支持针对每个数据条目定义生效范围（如全局不变、跟随当前人物卡、跟随特定对话或是浏览器内存态）。
- [ ] **Unified Settings (统一概览设置)**：点开设置栏时先显示大面板概览（如框架级的主题总控，和各个插件的核心“Common”设置），而不是直接跳转到排版详情。
- [ ] **Detailed Plugin View (插件独立详情页)**：为 `Settings`、`Timeline`、`Chat` 建设属于他们的独立详设页面，并在概览页中留出“跳转以配置详情（向右箭头 />）”按钮。
- [ ] **对话记录存储解耦**：允许聊天流也托管进本存储引擎中，可选保存到本插件拓展数据或直接导出到对应的 World Info 世界书中。
