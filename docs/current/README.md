# Current Tasks

这里记录仍在执行或需要持续跟踪的文档任务。

## 目录规则

```text
docs/current/tasks/<task-name>/
├── README.md
└── steps/
```

- `README.md` 记录任务目标、当前状态、下一步和恢复方式。
- `steps/` 只放当前未完成或仍需持续跟踪的步骤。
- 任务完成后，整个 `<task-name>/` 目录移动到 `docs/archive/completed-tasks/<task-name>/`。
