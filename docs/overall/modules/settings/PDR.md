# LuminaWeave Settings 子插件 - 产品需求文档 (PDR)

**版本:** v1.0
**所属系统:** LuminaWeave V2

## 一、 定位与愿景
对标现代长篇小说阅读软件（如起点、微信读书）。`Settings` (幻光设置) 提供沉浸式聊天界面的 UI 风格调整中心，使用户能够自定义聊天和文档视图中的字号、行距和间距。

## 二、 核心功能
1. **多级精确调控**：包括字号（`FontSize`）、行高（`LineHeight`）、段落间距（`ParagraphSpacing`）以及全屏界面的最大内容宽度（`ChatMaxWidth`）。
2. **多模态一键切换**：支持从原版聊天气泡式的 `Chat Mode` 切换为纯文字的 `Document Mode` 网文沉浸观读体验。
3. **设置项作用域 (Scope) 选择**：每项设置并非死板存在。用户可自由选择它是否“全局生效 (Global)”、还是“随当前角色卡绑定生效 (Character)”、亦或者是“仅此窗口生效 (Session)”。

## 三、 用户体验 (UI 层级重构)
1. **统一设置概览页 (Unified Page)**：点击顶栏右上角设置图标后弹出。罗列出所有子插件暴露的“常用设置 (Common Settings)”和框架总开关。
2. **插件独立详情页 (Detailed Page)**：在概览页只需点击子插件名（或右侧箭头），即可深入进入该插件专属、全部的设置项目列表中。极尽克制以免主设置界面变动臃肿。
3. 面板包含滑动条 (Range Input) 与精确数值显示双层结合。
4. “文档模式”开启后立刻剔除所有多余设计（边框、头像、名牌），直接达到类似电子书的效果。
