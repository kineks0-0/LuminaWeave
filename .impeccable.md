## Design Context

### Users
Hardcore roleplayers and AI enthusiasts using SillyTavern. They seek deep immersion, complex story management (branching timelines), and advanced memory systems. They are likely "power users" who appreciate technical depth but want a refined, efficient interface.

### Brand Personality
- **Voice**: Professional, advanced, and reliable.
- **Tone**: "Geek" yet premium. It should feel like high-end software for a specialized craft.
- **3-word personality**: Immersive, Orchestrated, Advanced.
- **Emotional goals**: Empowerment (I have full control), Confidence (The system remembers), Delight (Smooth, modern interactions).

### Aesthetic Direction
- **Visual tone**: "Modern Geek". This means clean lines, purposeful use of blur (glassmorphism), and a focus on hierarchy. It should avoid "AI slop" (neon-on-dark, generic cards).
- **References**: Likely influenced by modern IDEs (VS Code) or knowledge tools (Obsidian).
- **Anti-references**: Generic AI dashboard templates, cluttered legacy ST plugin UIs.
- **Theme**: Primary color is a refined Purple/Indigo (`#8b5cf6`). Neutral palette is tinted with blue/slate for cohesion.

### Design Principles
1. **Depth over Surface**: Design for functionality first. Spacing and hierarchy must support information density.
2. **Absolute Isolation**: Styles must be encapsulated (Shadow DOM) and never conflict with the host.
3. **Intentional Motion**: Use motion for state changes and feedback, not just decoration.
4. **Content is King**: The settings should be easy to read and adjust, with clear labels and helpful descriptions.
